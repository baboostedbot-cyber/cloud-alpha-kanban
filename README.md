# Cloud Alpha Kanban Board

Real-time kanban board for Cloud Alpha project management.

## Stack

- Next.js + TypeScript
- Tailwind CSS
- Supabase (real-time sync)

## Setup

```bash
npm install
cp .env.example .env.local
# Add your Supabase credentials
npm run dev
```

## Deploy

```bash
npx vercel --prod
```
